# Plant Care Expert System

A web-based expert system that generates customized to-do lists for planting, watering, and nurturing plants.

## Features

- User-friendly interface for searching plants
- Detailed plant information including planting conditions, watering schedules, and care instructions
- Customized to-do lists based on plant selection
- Admin panel for managing plant database
- Responsive design for all devices

## Installation
http://localhost/plant-expert-system
http://localhost/plant-expert-system/admin

### Requirements

- XAMPP (or any server with PHP and MySQL)
- Web browser
